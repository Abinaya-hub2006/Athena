Athena — AI Second Brain & Intelligent Academic Planner

Official Project Write-Up & Technical Architecture Report

Status: Core System Operational
AI Engine: Google Gemini 2.5 Flash
Database: Firebase Firestore

1. Executive Summary

Students, researchers, and knowledge workers face severe cognitive overload balancing fluctuating exam deadlines, topic mastery decay, daily routines, and task prioritization. Traditional task managers are static lists: they do not understand when the user works best, what topics they are struggling with, or why one task should take precedence over another.

Athena is an intelligent, context-aware "Second Brain" and proactive academic copilot. Built as an Android-first Progressive Web Application (PWA), Athena continuously models the user's cognitive state, academic commitments, memory bank, and energy patterns. Using a customized Learning-to-Rank (L2R) recommendation engine combined with Google Gemini 2.5 Flash, Athena automatically structures the user's day, provides reasoned task priorities, detects knowledge decay, and acts as an empathetic personal advisor.

2. Core Vision & Objectives

  • Active Context Retention (The Second Brain Vault): Automatically extract, categorize, and recall user habits, academic weaknesses, preferences, and personal goals in a centralized vault.
  • Explainable Task Prioritization: Eliminate decision fatigue by dynamically scoring tasks across 6 dimensions with human-readable rationales (e.g. deadline urgency, mastery gaps, energy alignment).
  • Adaptive Spaced Repetition & Topic Mastery: Track mastery decay curves across courses and exam dates, proactively queuing refresher sessions before knowledge is lost.
  • Context-Grounded Conversational Intelligence: A companion chatbot powered by Gemini that answers queries using real-time academic records, upcoming deadlines, and personal memories without hallucinations.
  • Zero-Friction Privacy & Resilience: Dual-mode persistence combining secure Cloud Firestore (with Google OAuth) and local offline-first storage fallback.

4. Work Completed So Far (Delivered Modules)

4.1. Intelligent Machine Learning Task Ranking Engine

  • Multi-Factor Scoring Matrix: Evaluates tasks across 6 dimensions: Deadline Proximity, Base Priority, Topic Mastery Gap, Energy Alignment, Effort Efficiency, and Context Momentum.
  • Explainable AI (XAI): Generates natural-language reasoning cards explaining exactly why Athena ranked each task in its position.
  • Online Weight Adaptation: Feedback loop capturing user accepts, skips, reorders, and completions to dynamically adjust algorithmic weights over time.

4.2. Second Brain Knowledge Vault

  • Structured memory categorization: Academic, Personal, Habit, Goal, Weakness.
  • Confidence scoring, star pinning, tag filtering, and real-time full-text search.
  • Automatic injection into Gemini system prompts for personalized recommendations.

4.3. Academic Course & Mastery Hub

  • Full course lifecycle management (Add, edit, track, delete subjects).
  • Syllabus topic mastery breakdown with visual percentage meters.
  • Exam countdown timers with urgency color coding.

4.4. Proactive AI Companion Chat

  • Server-side proxy shielding GEMINI_API_KEY from client exposure.
  • Dynamic system prompt synthesis injecting the user's real profile, study hours, weak topics, imminent deadlines, and memories.
  • Suggested conversation prompt pills for fast querying.

4.5. Daily Planner & Day Cockpit

  • Today's prioritized sprint view with task completion checklists.
  • Quick task creation modal with deadline picker, subject tagging, and priority tiering.
  • Real-time productivity analytics, streak calculation, and daily focus meters.

4.6. Authentication, Security & Dual Persistence

  • Google OAuth with Firebase Authentication integration and isolated Firestore user paths.
  • Local Development Mode bypass for instant testing without cloud dependencies.

4.7. DevOps, CI/CD & Local Tooling

  • Multi-stage Dockerfile creating a lightweight, production-ready runner image on port 3000.
  • GitHub Actions CI workflow for automated linting and build validation.
  • GitHub Actions CD workflow for continuous deployment to Google Cloud Run.
  • Visual Studio Code integration (.vscode/tasks.json, .vscode/launch.json) enabling single-click F5 debugging.

5. Balance Planned to Be Done (Roadmap)

Phase 1: High-Priority Next Deliverables (Immediate Focus)

  • Automated Memory Extraction from Chat: Equip Gemini chat agent with function calling to automatically detect and persist habits and exam dates from normal conversation.
  • Calendar Synchronization: Ingest external Google Calendar / iCal feeds to automatically schedule study blocks during free gaps.
  • Interactive Flashcards (FSRS Algorithm): Implement active recall flashcard sessions with Again/Hard/Good/Easy grading to calculate memory retention curves.

Phase 2: Medium-Term Enhancements

  • Web Push Notifications: Alerts before scheduled focus blocks and spaced repetition decay thresholds.
  • Document & Lecture Notes Ingestion (RAG): Upload PDF lecture notes or syllabi for automated topic breakdown and quiz generation.

Phase 3: Long-Term Innovations

  • Collaborative Study Groups: Anonymous peer benchmarking for course mastery and shared question banks.
  • Wearable & Biometric Energy Integration: Health Connect sync to dynamically adjust study goals based on physical recovery scores.

6. Conclusion

Athena bridges the gap between static task trackers and modern generative artificial intelligence. By pairing deterministic, explainable mathematical ranking algorithms with the contextual synthesis of Gemini 2.5 and the real-time reliability of Firebase Firestore, Athena provides students with an adaptive second brain that actively reduces cognitive friction and empowers academic mastery.
